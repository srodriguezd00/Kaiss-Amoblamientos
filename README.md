## 🚀 Cómo subir a GitHub Pages

1. Crear un repositorio nuevo en GitHub
2. Subir todos los archivos de esta carpeta (excepto `index_preview.html`)
3. Ir a **Settings → Pages**
4. En **Source** seleccionar **Deploy from a branch**
5. Elegir la rama `main` y carpeta `/ (root)`
6. Guardar y esperar 1-2 minutos
7. Tu sitio estará en `https://tu-usuario.github.io/nombre-repo`
